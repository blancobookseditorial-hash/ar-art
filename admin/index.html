Publish in GitHub

  1. Download the updated registry.json file above.
  2. Open your GitHub repository and create a new branch from main.
  3. Replace verify/registry.json with the downloaded file (keep the exact path).
  4. Create a pull request, test the Netlify preview, then merge it.

Always reload the latest registry before making another change. This starter handles one new certificate per downloaded file. It keeps all existing records untouched.
